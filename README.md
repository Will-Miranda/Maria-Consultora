# Maria Consultora

Uma landing page moderna e responsiva para Maria Consultora, especializada em produtos de bem-estar e saúde.

## 📋 Descrição

O projeto "Maria Vendas" é um site institucional desenvolvido para apresentar produtos de qualidade premium, focados em bem-estar e saúde. O site oferece uma experiência de navegação intuitiva com informações detalhadas sobre produtos, depoimentos de clientes e formulário de contato.

## 🚀 Funcionalidades

- **Design Responsivo**: Interface adaptável para desktop, tablet e mobile
- **Navegação Suave**: Menu com scroll suave entre seções
- **Galeria de Produtos**: Apresentação dinâmica dos produtos com preços e benefícios
- **Formulário de Contato**: Integração para comunicação direta com clientes
- **Redes Sociais**: Links diretos para WhatsApp e Instagram
- **Depoimentos**: Seção com feedbacks de clientes
- **Botão WhatsApp Flutuante**: Acesso rápido ao contato comercial

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilização moderna com design responsivo
- **JavaScript ES6+**: Funcionalidades dinâmicas e interatividade
- **Font Awesome**: Ícones para redes sociais e elementos visuais

## 🎯 Seções do Site

1. **Banner Principal**: Apresentação da Maria Consultora e chamada para ação
2. **Produtos**: Catálogo com informações detalhadas, preços e benefícios
3. **Comprar**: Seção de compras com opções de parcelamento
4. **Apresentação**: Sobre a Maria Luiza, consultora de vendas
5. **Depoimentos**: Feedbacks de clientes satisfeitos
6. **Contato**: Formulário para comunicação direta

## 🌐 Como Acessar

1. Clone o repositório:
   ```bash
   git clone <URL-do-repositório>
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd "Projeto Maria Vendas"
   ```

3. Abra o arquivo `index.html` em seu navegador preferido ou utilize um servidor local:
   ```bash
   # Com Python 3
   python -m http.server 8000
   
   # Com Node.js (se tiver instalado)
   npx serve .
   ```

4. Acesse `http://localhost:8000` no seu navegador.
